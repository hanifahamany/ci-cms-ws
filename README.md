# Content Management System - CodeIgniter 4

## 🛠️ Tech Stack
* **Framework:** CodeIgniter 4
* **Bahasa Pemrograman:** PHP 8.3.30 
* **Database:** MySQL
* **Composer 2.9.7** 

## 💻 Environment & Spesifikasi Perangkat
* **OS:** Windows 11 64-bit
* **Processor:** AMD Ryzen 5 5500U
* **RAM:** 16 GB
* **Storage:** 256 GB
* **GPU:** Radeon Graphics 2.1 GHz

## 🚀 Fitur
* Melihat, menambah, mengubah, dan menghapus pengguna
* Melihat, menambah, mengubah, dan menghapus produk
* Melihat, menambah, mengubah, dan menghapus transaksi pembelian
* Simulasi proses pembelian produk
* Relasi antara pengguna, produk, dan transaksi
* Tidak menggunakan authentication dan authorization sesuai ketentuan
