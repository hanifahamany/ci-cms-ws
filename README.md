# CI-CMS — Simulasi Pembelian Produk (CodeIgniter 4)

## 🛠️ Tech Stack
* **Framework:** CodeIgniter 4
* **Database:** Migration bawaan CodeIgniter (`php spark migrate`)
* **UI:** HTML dan CSS murni

* **Processor:** AMD Ryzen 5 5500U
* **RAM:** 16 GB
* **Storage:** 256 GB
* **GPU:** Radeon Graphics 2.1 GHz
